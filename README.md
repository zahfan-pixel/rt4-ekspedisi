# RT4 — EKSPEDISI

Website profil kelompok RT4 dan dokumentasi kegiatan EKSPEDISI.

## Menjalankan secara lokal
Buka `index.html` di browser. Website menggunakan HTML, CSS, dan JavaScript murni tanpa proses build.

## Publikasi GitHub Pages
1. Buka **Settings → Pages** pada repository.
2. Pada **Build and deployment**, pilih **Deploy from a branch**.
3. Pilih branch **main** dan folder **/(root)**, lalu tekan **Save**.
4. Tunggu proses publikasi selesai. URL biasanya menjadi https://zahfan-pixel.github.io/rt4-ekspedisi/.

## Bagian yang perlu diganti
- Profil: deskripsi, latar belakang, visi, misi, dan tujuan RT4.
- Anggota: ganti placeholder foto, nama, dan peran dengan data asli.
- Ekspedisi dan jurnal: isi cerita serta rangkaian aktivitas yang benar.
- Galeri: ganti foto contoh dari Unsplash dengan dokumentasi asli RT4 dan sesuaikan caption.

Foto yang sudah ada hanyalah gambar contoh bertema alam, bukan dokumentasi asli kelompok.
