# Background per Section

Ganti gambar dengan cara mengunggah file baru atau mengganti file lama di folder ini. Gunakan nama file yang sama agar website langsung memakai gambar terbaru.

| File | Section |
|---|---|
| home.jpg | Beranda |
| tujuan.jpg | Tujuan & Prinsip |
| anggota.jpg | Anggota |
| ekspedisi.jpg | Ekspedisi |
| timeline.jpg | Timeline Kegiatan |
| galeri.jpg | Buku Dokumentasi |
| video.jpg | Video Ekspedisi |
| penutup.jpg | Section penutup |

Format yang disarankan: JPG atau JPEG. Usahakan gambar landscape agar tampil rapi.

Section **Profil / Mengenal Kami** dan **Produk** memang tidak memakai background yang dapat diganti melalui folder ini.

Jika file gambar belum diunggah, website tetap menampilkan background cadangan yang sudah ada.
